# Playtest card

Draft v0. Print one per pair (A4, one side). Used from minute 8 to minute 35, next to the laptop. Print-ready file: [pdf/playtest-card.pdf](pdf/playtest-card.pdf).

| Minutes | Part of the card |
|---|---|
| 8-10 | 1. Before the build: each child writes a prediction |
| 10-17 | 2. Version 1 checks |
| 17-23 | 3. Someone else plays (creators watch and write) |
| 23-31 | 4. Version 2 plan: Change / Because / Keep / Check, and a prediction |
| 31-35 | 5. Retest: the result next to the prediction |
