# Idea card

Draft v0. Print one per pair (A4, one side). Used at minutes 5-8, before any laptop opens. Print-ready file: [pdf/idea-card.pdf](pdf/idea-card.pdf).

The five lines marked "Prompt" go into the five blanks under "Our game" in [lovable/starting-prompt.md](../../lovable/starting-prompt.md):

| Card line | Prompt blank |
|---|---|
| Our world | Our world |
| Colours and mood | Colours and mood |
| The secret code | The secret code |
| The clue: where it hides and what the player reads | The clue |
| The ending | Ending |

The other lines are extra. The pair uses them when they make the game their own at minute 10, and in Version 2.
