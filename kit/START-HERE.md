# Start here

Draft v0. Not ready for a class: waiting for Tomer's go-ahead and for the student route to be tested.

"Can your classmates escape a world you invented?" In 45 minutes, each pair builds a small escape game in Lovable through imagi Edu, watches a classmate play it and makes Version 2.
