# Scoring guide and observation sheet

Draft v0. Educator to check wording and difficulty before use. These are classroom checks, not validated measures of learning.

## Scoring the checks

| Check | 0 | 1 | 2 |
|---|---|---|---|
| Reason (Q1) | No relevant reason | Spots the failure | Uses the result and names an untested rule |
| Instruction (Q2) | Vague or breaks a rule | Specifies the change | Specifies the change and what to keep |
| Test (Q3) | Only "test it" | An action and expected result | Checks the fix and a kept rule, with expected results |

A strong answer to A spots that a wrong answer adds a point, says that the correct-answer and Restart rules are still unproven, asks for wrong answers to add zero while keeping the rest, and tests a wrong answer, a correct answer and Restart. B is the same with treasure and empty chests. Accept any equivalent reasoning.

Score each child alone. A pair's finished game is not an individual score. Missing answers stay missing, not zero.
