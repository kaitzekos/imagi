## If restore doesn't work for students

Use a Change / Keep / Check prompt that names the last working state:

```text
Undo the last change only. The game should work like before: ______. Keep everything else.
```

This depends on Lovable understanding "before", so test it once. If that fails too, the pair continues on the paper backup and the facilitator notes it.

## Prevention

- Before V2, the pair writes one line: "Version 1 works when ______."
- One change per prompt, so there is only one thing to undo.
