# Vision principles that apply to this class

From the Imaginable vision deck (revised 19 October 2026). Context, not scope: the deck describes an intended studio. This class uses existing tools.

- Agency is the goal. A child recognises their idea in the result, can explain a choice and wants to make another.
- The child invents the idea, chooses the audience and rules, judges what works and decides what to change. AI builds, offers possibilities and helps repair. Don't claim the child coded it.
- A personal idea already contains an audience and a way to play. Get the seed before AI supplies anything.
- No dense intake form before play. One meaningful decision, one visible consequence.
- A useful instruction has a purpose. Change / Keep / Check: what should be different, what must still work, what we will try next. Use it only when needed; remove the example once the child can do it.
- AI saying "done" is a claim. The child tries what should happen. Functional checks and first-player clarity are different questions.
- A real player reveals a different problem. The creator watches before explaining: where does the player hesitate? A player who was told the answer can test function but not first-time clarity.
- One observation becomes one improvement, predicted and then retested.
- Keep the working version. Try a change; go back if it makes things worse. Never promise a version system that hasn't been tested.
- Help increases only when needed: a prompt, then a clue, then a short model. Always hand the decision back.
- Persistence means a smaller next step, not pressing regenerate.
- Test a repair for side effects: test the change and test what should stay.
- Escape game logic as a chain the child can explain: clue, player action, rule, feedback. Test the right answer, a wrong answer and an empty answer.
- Taste is fit for purpose: a readable clue beats a cool unreadable font.
- Sharing: play first, then discover you can create. Count a new creator only when they start their own creation.
- Trust: nicknames only, adult-mediated sharing for under-13s, fictional content, no personal uploads.
- Do not treat compliments as return, finishing as mastery or a sent link as participation.
- Interface: one clear next action, the live game large, help close to the moment it's needed.
