# Brand

From the Imaginable brand pack. Proposed foundation, not final.

Wordmark: "imaginable", lowercase. Promise: "Make your ideas real".

| Token | Hex | Use |
|---|---|---|
| Paper | #F6F3EB | Default background |
| Ink | #211B2B | Text |
| Violet | #6C43FF | The main action |
| Lilac | #E5DDFF | Quiet emphasis |
| Lime | #D9F26F | A moment of surprise; use with ink text, never small white text |
| Muted | #68626F | Secondary text |
| Line | #D8D2DD | Rules and borders |

Type: Nimbus Sans Bold for headlines, Regular for body; Arial as fallback. Short lines, clear hierarchy, generous space.

Visual rules:

- The child's idea is the hero. Keep rough marks visible.
- Every visual has a job: show the idea, the game or the next action.
- Quiet interface, small palette, generous space. One idea per slide.
- No generic robots, glowing brains or floating tech icons.

Voice:

| Moment | Example |
|---|---|
| Starting | "What would make this feel like your game?" |
| Something fails | "The door stayed shut. What should happen after the code?" |
| Offering help | "Want a hint, or one more try?" |
| Finishing | "What did you change that made it work better?" |

Avoid baby talk, "Amazing!" after every click, inflated learning claims and abstract AI terms. Respect a child's decision to stop.

Children's games don't need Imaginable branding. Their world is theirs.
